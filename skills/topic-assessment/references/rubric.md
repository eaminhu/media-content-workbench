# 选题五维量表 v1

所有维度使用 1—5 分。1 分为关键条件缺失；2 分为有方向但明显不足；3 分为基本成立、仍需补充；4 分为依据具体且主要问题可解；5 分为关键条件充分、表达准确，且理由能指出输入中的支撑。缺失证据不能因语言流畅被评为充分。各分数是编辑判断，不是流量概率。不要以简单总分掩盖某一关键短板。

- reader_relevance / 读者相关性：目标读者是否具体；读者问题与其场景、需求是否匹配。泛泛的“所有人都关心”不足以支持高分。
- specificity / 切入具体度：对象、场景、核心问题和边界是否明确；一个选题是否塞入多个不相干问题。
- evidence / 证据支撑：用户是否提供可信来源、案例、可核查论断与限制。没有材料时明确列出缺口；不得假装模型记忆已经验证事实。
- cover_clarity / 标题清晰度：标题能否准确表达内容承诺，是否存在误导、错误前提、绝对化或只留下术语而没有读者问题。
- followup_potential / 延展价值：是否能讲出解释链、具体例子、实用价值，且与未来内容存在合理分工。重复和凑页数不是延展。

结论：
值得推进：已足以开始研究/写稿，不表示可以跳过事实核查。
建议调整：有可保留的方向，但需要修正明确短板。
资料不足：缺少足以判断核心价值、真实性或受众匹配的材料。

输出包含 summary、verdict、dimensions、strengths、risks、missingEvidence、nextStep。dimensions 每项包含 id、score、reason、action。
